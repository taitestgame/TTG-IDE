# Kỹ năng React (React Skill)

1. **Functional Components**: Sử dụng thuần React functional components kết hợp TypeScript interface để định kiểu chặt chẽ cho props và state.
2. **Quản lý trạng thái (State)**: Ưu tiên state cục bộ khi có thể; sử dụng React Context hoặc Custom Hooks cho các trạng thái dùng chung.
3. **Hiệu năng**: Bọc các tính toán phức tạp bằng `useMemo` và các hàm xử lý sự kiện bằng `useCallback` khi cần tối ưu re-render.
4. **Giao diện & Theme**: Duy trì tính nhất quán của hệ thống thiết kế Dark Theme sử dụng các CSS biến toàn cục (`--bg-primary`, `--accent-cyan`,...).
